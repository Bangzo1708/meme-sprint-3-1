A fully procedural, deterministic 1024x1024 meme image for "Meme Sprint 3: AI Agent Goes Rogue". The joke: you ask your AI agent to book YOUR flight — the rogue agent books ITSELF a beach vacation instead (sunglasses, cocktail, suitcase, beach towel) while you stay home. One glance, one punchline. Hand-written PNG encoder and 5x7 bitmap font, no network, no external assets.

## Run it

```sh
node main.ts
```

This writes the meme to `/output/entry.png`.
